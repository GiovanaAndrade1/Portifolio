Portifólio (no Framer)

Design
Visualizar projeto ↗

01 — A proposta

Este projeto consiste na criação do meu portfólio profissional, desenvolvido inicialmente no Framer, com o objetivo de apresentar minha trajetória, habilidades, projetos e experiências na área de tecnologia de forma visual, organizada e acessível.

A proposta é criar uma identidade visual que represente meu perfil como desenvolvedora de software, equilibrando estética, funcionalidade e uma navegação simples.

02 — Design

O design está sendo desenvolvido no Framer, explorando diferentes elementos de interface, animações, transições e interações para criar uma experiência mais dinâmica.

A estrutura foi pensada para apresentar as informações de forma clara, utilizando diferentes seções para destacar sobre mim, formação, habilidades, projetos e contato.

03 — Experiência do usuário

Um dos focos do projeto é criar uma experiência de navegação intuitiva e responsiva, garantindo que o conteúdo seja facilmente acessível independentemente do dispositivo utilizado.04 — Da interface ao código

O projeto não ficará limitado ao protótipo desenvolvido no Framer. A interface está sendo utilizada como base visual para uma versão completamente codificada do portfólio.

A próxima etapa consiste em transformar o design e as interações desenvolvidas no Framer em uma aplicação real, utilizando tecnologias de desenvolvimento web e reproduzindo as funcionalidades e animações através de código.

05 — Desenvolvimento

A versão codificada está sendo desenvolvida paralelamente ao design, permitindo aplicar na prática conceitos de desenvolvimento front-end, responsividade, componentes, animações e organização de interfaces.

Essa etapa também permite explorar como transformar uma interface visual em uma aplicação funcional, mantendo a identidade e a experiência planejadas durante o processo de design.
