PetMatch — adoção de cães e gatos

Desenvolvimento Web
Ver site ↗Ver no GitHub ↗

01 — A proposta

Desenvolvi o PetMatch entre 7 e 14 de outubro de 2026 como um site para uma ONG fictícia de adoção de cães e gatos em Belo Horizonte.

02 — Vitrine de animais

A página inicial apresenta seis animais e organiza o processo de adoção em quatro etapas. A seção Sobre apresenta a ONG e explica como funciona o lar temporário.

03 — Feiras e vacinas

Criei uma página para reunir informações sobre feiras de adoção e vacinação, com uma tabela para facilitar a consulta.

04 — Pré-cadastro

A interface inclui um formulário de pré-cadastro com validação nativa do HTML, campos obrigatórios e opção para limpar as informações preenchidas.

05 — Interface responsiva

Usei HTML semântico e CSS para adaptar o layout a diferentes tamanhos de tela. O menu móvel funciona apenas com HTML e CSS, e os estilos respeitam a preferência do sistema por movimento reduzido.
