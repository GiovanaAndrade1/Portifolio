NaCarteira

Mobile
Conversar sobre o projeto →

01 — O problema

Organizar as finanças pessoais pode ser difícil quando as pessoas não possuem uma forma simples de acompanhar seus gastos, entradas e movimentações financeiras.

Pensando nisso, o NaCarteira foi desenvolvido como uma aplicação mobile voltada para facilitar o controle financeiro, permitindo que o usuário registre suas movimentações e acompanhe sua situação financeira de maneira mais organizada.

02 — A solução

O NaCarteira é um aplicativo desenvolvido para gerenciamento de finanças pessoais, permitindo registrar entradas e despesas e acompanhar as movimentações realizadas.

A aplicação possui uma tela inicial que apresenta um resumo das movimentações e calcula os valores de entradas e despesas, além de permitir adicionar novos registros informando descrição, valor, data e tipo da movimentação.

03 — Desenvolvimento

O aplicativo foi desenvolvido utilizando React Native, permitindo a criação de uma aplicação mobile com uma estrutura baseada em componentes e diferentes telas de navegação.

A aplicação utiliza React Navigation para organizar a navegação entre as páginas e componentes reutilizáveis para elementos como cabeçalho, saldo, ações e movimentações.

Também foram utilizadas animações para tornar algumas interações mais fluidas, incluindo transições durante o cadastro de movimentações e interações por gesto.

04 — Banco de dados e autenticação

Para armazenar as informações, o projeto utiliza o Firebase, com o Cloud Firestore como banco de dados.

Os dados das movimentações são organizados de acordo com cada usuário autenticado, permitindo que cada conta tenha acesso às suas próprias informações financeiras.

A autenticação também utiliza o Firebase, enquanto o AsyncStorage é utilizado para manter a persistência da sessão no ambiente mobile.

05 — Funcionalidades

Entre as funcionalidades implementadas estão:

Cadastro de entradas e despesas

Registro de descrição, valor e data

Classificação entre entrada e despesa

Cálculo do total de entradas

Cálculo do total de despesas

Listagem das últimas movimentações

Exclusão de movimentações por gesto

Autenticação de usuários

Persistência dos dados no Firebase

Navegação entre diferentes áreas do aplicativo

Seleção de datas

Interface com animações e transições

06 — Experiência mobile

Um dos pontos trabalhados no projeto foi a criação de uma experiência adequada para dispositivos móveis.

Além da navegação entre telas, foram utilizadas interações por toque e gestos, como o recurso de deslizar uma movimentação para excluí-la. Também foram utilizadas animações com a biblioteca Moti, tornando a interação com o aplicativo mais dinâmica.

08 — Objetivo

O objetivo do projeto foi desenvolver uma aplicação mobile capaz de simplificar o controle das finanças pessoais, aplicando na prática conceitos de desenvolvimento mobile, gerenciamento de estado, navegação, autenticação e integração com banco de dados.

Além da construção da interface, o projeto permitiu trabalhar com a integração entre aplicação mobile e serviços em nuvem, criando uma experiência na qual os dados financeiros são armazenados e associados ao usuário autenticado.

Trabalho em equipe

O NaCarteira foi desenvolvido em equipe, envolvendo diferentes integrantes no processo de construção da aplicação. O projeto proporcionou experiência com desenvolvimento colaborativo, divisão de responsabilidades e integração das diferentes partes de uma aplicação mobile.
