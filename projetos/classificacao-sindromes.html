Classificação de síndromes com Machine Learning

Machine Learning
Visualizar projeto ↗

01 — O contexto

Desenvolvi este projeto como teste técnico em um processo seletivo, trabalhando com a classificação de síndromes a partir de embeddings de imagens. Com um prazo curto, foquei na construção de um pipeline funcional e na comparação das escolhas de modelagem.

02 — Preparação e exploração dos dados

O fluxo começa com o carregamento e a preparação dos embeddings, representações numéricas utilizadas como entrada para o classificador. Os rótulos são codificados para a classificação, e a distribuição das classes é explorada para compreender os dados.

Utilizei t-SNE para visualizar os embeddings em duas dimensões e observar a distribuição das amostras entre as diferentes classes. O gráfico ajuda na exploração dos dados, sem substituir a avaliação do modelo.

03 — Classificação com KNN

Implementei a classificação com K-Nearest Neighbors (KNN), comparando as distâncias euclidiana e cosseno. O número de vizinhos varia de 1 a 15, permitindo analisar como esse parâmetro influencia o comportamento do classificador.

04 — Avaliação dos modelos

A avaliação utiliza validação cruzada estratificada em 10 partições. O pipeline calcula AUC, F1-Macro e Top-k Accuracy e gera gráficos comparativos, além de uma tabela-resumo com as melhores configurações para cada métrica e distância.

A F1-Macro atribui o mesmo peso a cada classe, contribuindo para analisar o desempenho além das classes mais frequentes. As métricas são observadas em conjunto para comparar as configurações avaliadas.

05 — Organização do projeto

O código está organizado em módulos de processamento dos dados, visualização, classificação e avaliação. Um ponto de entrada executa o fluxo e salva os gráficos em PNG e a tabela de resultados em CSV.

06 — Tecnologias e conceitos

Python, NumPy, pandas, scikit-learn, Matplotlib e Seaborn. Embeddings de imagens, KNN, distância euclidiana, distância cosseno, validação cruzada estratificada, t-SNE e métricas de classificação.

07 — Aprendizados

O projeto contribuiu para aprofundar conhecimentos em classificação e avaliação de modelos, que também se relacionam ao meu projeto principal: a classificação de glaucoma em imagens retinianas com inteligência artificial.
